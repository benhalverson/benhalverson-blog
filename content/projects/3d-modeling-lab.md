## Overview

This project groups together the part of the work that is not really software and not really a single product either: fixtures, printable utilities, enclosure ideas, and repeatable modeling patterns.

## Current milestone

Publish the first set of reusable designs with cleaner naming, tolerancing notes, and print guidance.

## Roadmap

- [ ] Organize models by problem space instead of by date
- [ ] Add print-orientation and tolerance notes
- [ ] Build a release process for printable artifacts
- [ ] Document reusable modeling patterns
- [ ] Separate quick experiments from maintained designs

## Notes

This area benefits from being public because it makes iteration visible. A small modeling decision is often much easier to understand when the discarded alternatives are visible too.
